# Archived problem categories

The active app serves only the 25 variants. The original and new categories are archived, not deleted.

`activeCategories` in `visual-library.js` lists only `variant`; original/new entries are explicitly commented out. The picker omits them and their direct lesson URLs show the variant picker with an archive message. The full reference bank remains available to authoring tools so variant parent links, stable question indices, and future restoration remain intact.

Keep the original/new `visual-specs`, `visual-lessons`, Step 2 and Step 4 source files. They are not active app content. Validate the complete bank for consistency, but only variants appear in the current app.
