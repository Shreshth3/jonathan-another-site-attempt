# Step 4 review: original problems

Source of truth: each published reference solution in `../jonathan-study-site/site/problems.js`.
Every accepted case changes one rule, uses an input that exposes that change, and has executable code.

## Reviewed inventories

- **All Paths From Source to Target.** Correct rule: recursively prepend each node to every suffix path and collect every route to the last node. Cases: `authored-deep-case` (global visited wrongly merges routes), `first-branch-only`, `direct-paths-only`. Excluded: cycle handling, because the input is guaranteed to be a DAG.
- **Keys and Rooms.** Correct rule: start in room 0 and follow every newly found key until reachability stops. Cases: `authored-deep-case` (reverse key edges), `direct-keys-only`, `every-room-has-key`. Excluded: missing-key IDs, because keys are guaranteed to name valid rooms.
- **Kill Process.** Correct rule: build parent-to-child edges and return the killed process plus its full descendant subtree. Cases: `authored-deep-case` (only immediate children), `children-without-kill`, `walks-to-parent`. Excluded: cycle protection, because the process relation is a tree.
- **Letter Combinations of a Phone Number.** Correct rule: choose one mapped letter for every digit and emit only full-length strings. Cases: `authored-deep-case` (stops one digit early), `one-letter-per-digit`, `three-letters-for-seven-nine`. Excluded: mappings for 0 and 1, because the problem input uses digits 2–9.
- **Longest Increasing Path in a Matrix.** Correct rule: try every cell as a start and follow all four side directions to strictly larger values; length counts cells. Cases: `authored-deep-case` (down/right only), `starts-at-top-left`, `counts-edges`, `allows-equal-steps`. Excluded: a visited-set bug, because correct strict increases make cycles impossible.
- **Minesweeper.** Correct rule: a mine click becomes X; otherwise count eight local neighbors and recursively reveal only zero-mine cells. Cases: `authored-deep-case` (four-neighbor count), `counts-all-mines`, `mine-click-becomes-blank`. Excluded: rectangular-board bounds mistakes as generic indexing errors rather than graph-rule misunderstandings.
- **Nested List Weight Sum.** Correct rule: outer integers have depth 1 and each nested list adds exactly one to the multiplier. Cases: `authored-deep-case` (outer depth 0), `same-weight-every-depth`, `depth-increases-by-two`. Excluded: integer parsing mistakes, which are not traversal misconceptions.
- **Nested List Weight Sum II.** Correct rule: weight is `maximum depth - integer depth + 1`. Cases: `authored-deep-case` (ordinary depth weights), `all-weight-one`, `off-by-one-max-depth`. Excluded: breadth-first versus depth-first traversal, because either traversal is correct when depths are recorded correctly.
- **Network Delay Time.** Correct rule: preserve directed weighted edges, keep the fastest arrival per node, return the latest arrival, and return -1 if any node is unreachable. Cases: `authored-deep-case` (makes edges two-way), `fewest-hops`, `sums-all-arrivals`, `ignores-unreachable-node`. Excluded: negative-weight handling, because travel times are positive.
- **Battleships in a Board.** Correct rule: count four-direction connected components of X cells, including one-cell ships. Cases: `authored-deep-case` (horizontal starts only), `counts-ship-cells`, `skips-single-cell-ships`. The old diagonal-merge case was removed because its diagonally touching ships violated this problem's input guarantee. Excluded: malformed L-shaped ships for the same reason.
- **Course Schedule.** Correct rule: reject only a directed cycle, using the active recursion path rather than all previously visited nodes. Cases: `authored-deep-case` (any visited node means cycle), `edge-means-cycle`, `checks-mutual-pairs-only`. Excluded: reversing every prerequisite edge, because cycle existence is unchanged by reversing the whole graph.
- **Detonate the Maximum Bombs.** Correct rule: build a directed edge when the target center lies within the source radius, then try a full chain reaction from every bomb. Cases: `authored-deep-case` (forces symmetry), `direct-hits-only`, `starts-first-bomb`. Excluded: square-root precision, because squared distances avoid that issue cleanly.
- **Evaluate Division.** Correct rule: store reciprocal reverse edges, multiply ratios along a reachable path, return 1 for a known variable divided by itself, and -1 when either variable is unknown. Cases: `authored-deep-case` (wrong reciprocal), `adds-ratios`, `no-identity-query`, `unknown-identity-is-one`. Excluded: choosing among several consistent paths, because valid inputs do not contain contradictory equations.
- **Find If Path Exists in Graph.** Correct rule: treat edges as undirected and search from the supplied source through any number of hops. Cases: `authored-deep-case` (one-way edges), `direct-edge-only`, `starts-at-zero`. Excluded: shortest-path logic, because only existence matters.
- **Flatten Nested List Iterator.** Correct rule: recursively visit every nesting depth while preserving left-to-right integer order. Cases: `authored-deep-case` (assumes one nested level), `reverses-folder-contents`, `drops-top-level-values`. The repeated second one-level bug was replaced with a distinct ordering mistake. Excluded: iterator caching details, which do not change the nested graph model.
- **Is Graph Bipartite.** Correct rule: color every connected component with opposite colors across each edge and reject any color conflict. Cases: `authored-deep-case` (checks one component), `rejects-any-cycle`, `ignores-color-conflicts`. Excluded: treating directed edges specially, because the input adjacency describes an undirected graph.
- **Number of Connected Components.** Correct rule: include all `n` nodes, add both directions for each edge, and launch a traversal from every unvisited node. Cases: `authored-deep-case` (one-way pairs), `counts-nodes-minus-edges`, `drops-isolated-nodes`. Excluded: union-find rank mistakes, because the shown teaching solution uses traversal.
- **Number of Increasing Paths in a Grid.** Correct rule: every cell starts a path; recursively count every four-direction strictly increasing continuation. Cases: `authored-deep-case` (bottom/right only), `starts-at-minimum`, `counts-cells-only`, `allows-equal-steps`. The bad code uses a current-path set only to terminate its invalid equal-value moves cleanly.
- **Number of Islands.** Correct rule: count side-connected components of land cells only. Cases: `authored-deep-case` (diagonal edges), `counts-land-cells`, `counts-water-components`. Excluded: mutating versus non-mutating visited storage, because both implementations can be correct.
- **Number of Provinces.** Correct rule: scan every city and count each new connected component in the adjacency matrix. Cases: `authored-deep-case` (only first province), `direct-from-zero`, `diagonal-is-province`. Excluded: matrix symmetry mistakes, because the province matrix is guaranteed symmetric.
- **Possible Bipartition.** Correct rule: color every dislike component with two opposite groups and reject any same-group dislike edge. Cases: `authored-deep-case` (checks only person 1's component), `rejects-any-dislike-chain`, `ignores-group-conflicts`. Excluded: self-dislikes, because each dislike pair contains two different people.
- **Smallest String With Swaps.** Correct rule: find undirected connected index components, then assign each component's sorted characters to its sorted indexes. Cases: `authored-deep-case` (one-way pair), `one-pass-swaps`, `sorts-whole-string`. Excluded: duplicate pair handling, because repeated edges do not change components.
- **Time Needed to Inform All Employees.** Correct rule: build manager-to-subordinate edges and add each manager's time to the maximum, not sum or minimum, of parallel child branches. Cases: `authored-deep-case` (sums branches), `shortest-branch`, `omits-head-delay`. Excluded: adding leaf delay, because valid inputs require leaves to have zero inform time.
- **Water and Jug Problem.** Correct rule: the target must not exceed total capacity and must be divisible by the capacities' greatest common divisor. Cases: `authored-deep-case` (target must sit in one jug), `must-fill-exact-jug`, `capacity-sum-enough`. Excluded: illegal partial-fill moves, because the two accepted arithmetic cases isolate the same reachability boundaries more cleanly.
- **Word Search.** Correct rule: try every cell as a start, follow side neighbors matching the next letter, prevent reuse only on the current path, and backtrack. Cases: `authored-deep-case` (global visited), `diagonal-steps`, `reuse-same-cell`, `starts-top-left-only`. Excluded: reverse-word optimization, because it changes speed but not correctness.

## Fresh adversarial findings and repairs

- **Blocker fixed — Battleships:** the removed diagonal case used an input forbidden by the statement. It now tests the realistic mistake of ignoring valid one-cell ships.
- **Major fixed — Minesweeper:** the old “clicked mine” case actually clicked an empty cell, so its diagnosis was false. It now clicks the mine and isolates the wrong `B` versus `X` mark.
- **Major fixed — Flatten Nested List Iterator:** two cases tested the same one-level flattening bug. One now tests reversing folder contents, a separate ordering obligation.
- **Major fixed — Keys and Rooms:** the old empty-room explanation referred to another room that did not exist. The input now has room 0 unlock a valid empty room 1.
- **Major fixed — canned review text:** generated cases no longer use unrelated “reverse every edge” and “wrong start node” choices for every problem. Their choices now stay within that problem's real mistake family, and every proof states the exact two outputs.
- **Missing core rules added:** strict inequality for both increasing-path problems, unreachable-node handling for Network Delay, unknown identity queries for Evaluate Division, and scanning every start cell for Word Search.
